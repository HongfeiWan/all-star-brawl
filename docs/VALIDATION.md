# v0.1.0 验证记录

日期：2026-10-13。测试环境：macOS、Node.js 25.9.0、Blender 5.1.1、桌面 Chrome。兼容目标：Node.js 22+。

## 自动检查

`npm run check`：**12 项全部通过**。

- GLB 文件完整性、16 骨骼蒙皮与每名角色的七个动画片段。
- 无效招式、气势不足、默认格挡与气势上限。
- 普通伤害、重击破防、三名角色绝招和王司徒的气势消耗。
- 双方从同一状态结算，支持双 KO；生命比例判胜。
- 回合重置保留玩家与比分。
- 两个真实 WebSocket 客户端的建房、加入、开始与对战。
- 对手招式在选招阶段保持隐藏，锁定后不可修改。
- 超时自动格挡、人机陪练和房间清理。
- 断线后房间回到准备阶段。
- 无效消息、满房间、伪造伤害、私有文件路径和跨源连接。
- 平局重开同一局、两胜结束与房主再战。

`npm audit --omit=dev --audit-level=high`：**0 个已知漏洞**。

## 真实浏览器

Playwright CLI 驱动已安装的 Chrome，未增加项目测试依赖。

- 1440 × 960 画面：三个角色逐一检查，GLB、材质和动画正常加载。
- 完成一场人机对战，经过选招、出招、伤害、局间过渡与最终胜负。
- 点击再战，生命与比分重置；离开后返回大厅。
- 两个浏览器标签：主机使用 localhost，客端使用本机真实 LAN IPv4 地址。通过大厅加入、房主开始、重击对格挡测试；两端显示 **76 / 100 HP**，进入第二回合，断线回到准备阶段。
- 390 像素宽度无横向溢出，玩法弹窗正常打开和关闭。
- 最终页面没有浏览器控制台错误或警告。
