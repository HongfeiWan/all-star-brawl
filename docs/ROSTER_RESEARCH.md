# 鬼畜全明星角色调研与游戏名册

调研截止：2026-10-13。合并影视、经典素材、舞台和近年网络人物资料，共 128 个身份入口。调研集已纳入游戏角色数据；它不是 B 站官方名单，也不是一个封闭、永久不变的「全部鬼畜素材」全集。新的投稿、地区梗和冷门素材仍会继续出现。

每项先核对素材中的人物，再制定原创的服装、道具、台词和招式。链接用于辨认素材来源，不代表已取得其原视频、音乐、演员肖像或品牌资产的再发布许可。仓库不随此名册搬入原片、原音或第三方模型。

资料人物与模型精度分别验收：资料中的姓名、别名和作品对应关系有来源；游戏模型采用风格化轮廓和不同的服装、发型、脸型、体型、配件与道具组合，不宣称是扫描级真人还原。表情与身体动画还需在实际对战画面中观察。

研究配置保留原三位的动作参考分类；新增人物在游戏中实际使用 `ROSTER_MOTIONS` 指定的刀式、圆形道具、长柄及徒手四类动作库。原三位各保留七个片段，四个新库也各有七个片段，共 49 个实际片段。共享动作库不等于 128 人各自完成独立动作捕捉；单人专属动画可继续替换，不应以名册条数代替动作质量。

本轮数值是可玩的初始参数：生命 100–116、绝招伤害 30–40。原三位的属性和台词保留，王司徒保留消耗对手 1 点气势的效果；新角色的强度仍需通过实际对局调整。

## 更新方式

角色与来源只维护在 `shared/roster.js` 的纯 JSON 数组中。新增人物前先检查姓名、别名、原作角色和扮演者的对应关系；同一人物的新名场面增加来源或外观，不重复增加角色。每次扩展都继续检查道具、表情、接触点、前摇与回收动作，并在实际视角中验收。
